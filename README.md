# Plataforma Moodle

Proyecto de análisis, diseño, viabilidad, prototipo y validación de una plataforma centralizada de acceso a los distintos entornos Moodle de la organización, según la *Ficha de proyecto 01 — Plataforma centralizada para los entornos Moodle*.

## Estado actual

| Fase | Nombre | Estado |
|---|---|---|
| 1 | Descubrimiento | **Borrador completo** (v0.4), pendiente de revisión del tutor |
| 2–8 | Requisitos, Alternativas, Diseño, Viabilidad, Prototipo, Validación, Cierre | No iniciadas. No se avanza hasta el visto bueno de la Fase 1. |

## Dónde está cada cosa

- [`Fase-1/`](Fase-1/README.md): toda la documentación de la fase de descubrimiento, con su índice, registro de cambios, registro de seguimiento e histórico de versiones. Para una visión rápida, empieza por el [Diagnóstico inicial](Fase-1/08-diagnostico-inicial.md).

## Reglas básicas

- No se guardan en este repositorio contraseñas, tokens, cookies, credenciales ni datos personales.
- No se accede a áreas privadas de ningún campus Moodle ni se realizan pruebas intrusivas.
- Todo lo que no esté comprobado se marca como supuesto o pendiente de confirmar.
