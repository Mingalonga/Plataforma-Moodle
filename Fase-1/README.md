## Convención de versiones

- Cada documento lleva una cabecera con versión, fecha, estado y autoría, y al final una tabla de control de versiones.
- Las versiones `0.x` son borradores. La versión `1.0` se asigna cuando el tutor valida el documento.
- Cuando un documento ya revisado cambia de versión, la versión anterior se copia en [`historico/`](historico/README.md) y el cambio se anota en el [`CHANGELOG.md`](CHANGELOG.md).
- Cada revisión, con sus acuerdos, se anota en el [`registro-seguimiento.md`](registro-seguimiento.md).
- El historial de Git conserva además todos los cambios intermedios.

## Clasificación de la información

Siguiendo el prompt inicial, cada afirmación se etiqueta con su origen:

| Etiqueta | Significado |
|---|---|
| **[H]** Hecho comprobado | Verificado con evidencia registrada |
| **[O]** Observado en web pública | Visto en una página pública, con fecha de consulta |
| **[D]** Dato de la organización | Facilitado por el propietario, el tutor o un responsable |
| **[S]** Supuesto | Hipótesis de trabajo no confirmada |
| **[R]** Recomendación | Propuesta del equipo de proyecto |
| **[P]** Pendiente de autorización | Requiere permiso o decisión antes de avanzar |
